# Asaaan Launcher 0.1.0

The first public release of Asaaan Launcher: a keyboard-first desktop launcher for Linux, macOS, and Windows.

## Highlights

- Fuzzy application search with aliases, favorites, usage ranking, and hidden results.
- A minimal launcher with system light/dark appearance and an optional Legacy theme.
- Focused-monitor placement on supported desktops and bounded panel reuse for quick reopening.
- General and Applications settings, search-history controls, and native application actions.
- Bundled extension Lists with keyboard actions and resumable sessions.
- Headless application search and an interactive command-line picker.

## Current scope

- Extension commands are bundled; arbitrary extension installation, Detail/Form views, a store, and scheduling are not included.
- Wayland shortcut and monitor-placement support depends on the compositor.
- Running-app controls are available only when native identity and capabilities can be verified.
- This public version replaces internal checkpoint numbering; it does not reset preferences.

See the [README](https://github.com/AsaanKaroobar/Asaan-Launcher/blob/0.1.0/README.md) for setup, usage, and development instructions.
