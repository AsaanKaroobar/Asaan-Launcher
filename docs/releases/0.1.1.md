# Asaaan Launcher 0.1.1

Fixes repeated focus changes on Windows that interrupted typing and immediately closed the Actions menu. Search editing and Actions now remain stable, while hiding and reopening the launcher retains the existing presentation behavior.

This is a CP014 bug-fix release. It does not add later extension views or change checkpoint scope.
