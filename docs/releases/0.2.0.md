# Asaaan Launcher 0.2.0

Asaaan Launcher 0.2.0 adds native Wayland and Hyprland support and includes the Windows focus-loop repair shipped in 0.1.1. Existing X11, macOS, and Windows behavior is retained.

## Highlights

- Includes the 0.1.1 Windows focus repair: search editing and the Actions menu remain stable through duplicate native focus notifications.
- Native Wayland support: `asaaan-launcher --toggle` with a compositor binding, plus tray access.
- Hyprland placement and focus: the launcher, Settings, and picker float, size, center on the focused monitor's usable area, and focus through Hyprland's local IPC.
- Picker focus recovery so keyboard filtering works on Wayland.
- Wayland presentation fixes: opaque surfaces, a fresh first frame after a hidden-created panel loads, and no pre-map size flash.
- New `npm run test:wayland:hyprland` and `npm run test:wayland:windows` native checks, alongside the existing X11 regression suites.
- Local installation on non-Debian hosts via `bsdtar` when `dpkg-deb` is unavailable.

## Current scope

- Wayland global shortcuts use a compositor binding (`--toggle`); no portal global-shortcut service is implemented.
- Hyprland placement and focus are tested. Other Wayland compositors keep their own placement and focus policy.
- Running-app controls remain unavailable on Wayland.
- Extension commands are bundled; arbitrary extension installation, Detail/Form views, a store, and scheduling are not included.
- This release does not reset preferences.
