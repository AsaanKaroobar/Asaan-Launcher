# Asaaan Launcher 0.3.0

Asaaan Launcher 0.3.0 adds signed automatic updates, with a startup Install/Later prompt and a tray **Check for updates…** action. It retains the 0.2.0 Wayland/Hyprland support and the Windows focus repair.

## Highlights

- Signed update checks with a startup prompt and tray action; updates are never installed silently.
- Linux AppImage updates download, verify, replace the AppImage and restart automatically.
- Linux `.deb` installs remain manual; the app explains that automatic installation requires the AppImage.
- Windows NSIS and macOS app-bundle updates use the same signed `latest.json` manifest.
- `requireSignedVersion` rejects an artifact whose signature version does not match the announced release.
- Retains Wayland/Hyprland placement, focus, keyboard and rendering support, and the Windows focus-loop fix.

## Downloads

Install the package matching your operating system and architecture. SHA-256 checksums are included in `SHA256SUMS`. Linux users who want automatic updates should use the AppImage; the `.deb` remains available for manual installation.

These builds are unsigned; the macOS app is not notarized. macOS automatic updates may require signing/notarization before Gatekeeper accepts them, and Windows SmartScreen may warn about unsigned installers. Linux AppImage updates are user-writable and do not require root. Windows and macOS builds pass CI checks and packaging; 0.3.0 updater desktop qualification remains pending.

**0.2.0 and earlier cannot auto-update.** Install 0.3.0 manually; 0.3.0 and later can update automatically.

## Current scope

- The updater checks GitHub Releases; there is no update-management preference or daily cache yet.
- Linux automatic updates are AppImage-only.
- Extension commands are bundled; arbitrary extension installation, Detail/Form views, a store, and scheduling are not included.
- This release does not reset preferences.

See the [README](../../README.md) for setup, usage, and platform notes. The first updater-capable release is 0.3.0; it publishes `latest.json` for subsequent releases.
