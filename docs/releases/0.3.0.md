# Asaaan Launcher 0.3.0

Asaaan Launcher 0.3.0 adds signed automatic updates, with a startup Install/Later prompt and a tray **Check for updates…** action. It retains the 0.2.0 Wayland/Hyprland support and the Windows focus repair.

## Highlights

- Signed update checks with a startup prompt and tray action; updates are never installed silently.
- **Default shortcut:** Ctrl+Alt+Space on X11 and Windows. On Wayland, bind Ctrl+Alt+Space in the compositor to `asaaan-launcher --toggle`.
- Linux AppImage updates download, verify, replace the AppImage and restart automatically.
- Linux `.deb` installs remain manual; the app explains that automatic installation requires the AppImage.
- Windows NSIS and macOS app-bundle updates use the same signed `latest.json` manifest.
- `requireSignedVersion` rejects an artifact whose signature version does not match the announced release.
- Retains Wayland/Hyprland placement, focus, keyboard and rendering support, and the Windows focus-loop fix.

The installers are not developer signed; the macOS app is not notarized. macOS automatic updates may require signing/notarization before Gatekeeper accepts them, and Windows SmartScreen may warn about unsigned installers. Linux AppImage updates are user-writable and do not require root. Windows and macOS builds pass CI checks and packaging; 0.3.0 updater desktop qualification remains pending.

**0.2.0 and earlier cannot auto-update.** Install 0.3.0 manually; 0.3.0 and later can update automatically.
