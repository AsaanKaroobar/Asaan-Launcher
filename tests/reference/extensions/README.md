# Extension foundation provenance

Pinned Floe: 5b26e9d7a0240243251d7421bee5b90da5f52b9b. © 2026 René Jiménez, GNU AGPLv3. Original headers are retained. Frozen sources are test-only and are excluded from packaged resources.

CP013 ports manifest and NDJSON/reference-v1 decoding into crates/launcher-extensions. Original runtime source, lockfile and all twelve test files are imported. Test subprocesses use process.execPath and an explicit private Asaaan support directory; the parity checker verifies that these are the only changes to original runtime assertions. Platform-specific API tests use their original mocks; they do not establish actual clipboard, app, file, OAuth, UI or native integration parity.

The ledger includes every declaration in the four scoped Swift test files, SessionTests (mostly deferred), and the twelve runtime test files. inventory.json freezes these IDs independently of mapping/status changes. Runtime parameterized tests expand to 275 executed cases. Original macOS Swift execution remains unavailable. Native Linux acceptance uses the installed executable and bundled Bun; Windows/macOS native execution is unverified.

Intentional boundaries: safe extension/command slugs reject path separators and drive syntax; platform lists/defaults select macOS, Windows or Linux explicitly, with absent lists meaning all and an empty list meaning none. Missing Linux defaults are not replaced with a Mac default. No List UI, store installation, scheduling, session navigation model, memory qualification, login-shell environment discovery, preferences/secrets resolution or general native API dispatcher is enabled. Copied runtime API Mac shortcuts, direct Finder/Trash/app queries and access path display still need portability work before exposing arbitrary extensions. Hosts remain unsandboxed, as in Floe.

Added resource/transport limits (8 MiB NDJSON line, 100,000 expanded tree nodes, depth 128 plus serde_json’s default JSON nesting bound, 64 KiB input/arguments, sixteen queued pipe chunks/writes) are explicit host boundaries rather than claims of unlimited protocol parity. Only the latest render is held, unresolved references ask for a full render once, and independent hosts never share revisions. Unix cleanup uses the owned host group; Windows has a kill-on-close Job implementation whose native behavior remains unqualified. Hard-killing an owning Unix process can bypass its cleanup; resident-owned interactive sessions and ownership/EOF integration are for CP014.
